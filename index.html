SUPPORT CENTER

Pusat Bantuan

Informasi singkat seputar pemesanan dan pembayaran.

Berapa batas maksimal match?

Kedua paket, FLEXIBLE dan NO FLEXIBLE, memiliki batas maksimal 5 match per pesanan.

Berapa harga setiap paket?

FLEXIBLE Rp2.500 per match. NO FLEXIBLE Rp3.500 per match. Total dihitung otomatis.

Apakah QRIS tampil di beranda?

Tidak. QRIS hanya ditampilkan di bagian pembayaran pada halaman Buat Pesanan setelah pesanan berhasil dibuat.

Apakah pembayaran diverifikasi otomatis?

Tidak. Website menampilkan gambar QRIS dan nominal, sedangkan verifikasi pembayaran perlu dilakukan admin.

Kenapa QRIS tidak muncul?

Periksa apakah file qris.jpg berada di folder yang sama dengan index.html dan ejaan nama file tepat.

Apakah riwayat tersinkron ke perangkat lain?

Tidak. Versi ini menggunakan localStorage pada browser. Sinkronisasi lintas perangkat memerlukan backend dan database.
